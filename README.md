# Molecular Vibration & Damping Lab 🧪
An interactive educational tool developed for Singapore Polytechnic to visualize molecular dynamics.

## 🚀 Live Simulation
**[https://molecular-vibration-app.streamlit.app/]**

## 📊 Key Features
* **Interactive Physics:** Real-time simulation of underdamped, critically damped, and overdamped systems.
* **Live Graphing:** Simultaneous visualization of molecular movement and displacement-time data.
* **Educational Presets:** One-click scenarios for classroom demonstrations (e.g., Viscous environments).

## 🛠️ Technical Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Graphics:** Plotly (JavaScript-based rendering for smooth animations)
* **Math:** NumPy (Differential equations & modeling)
